# API surface

The API is REST over JSON under `/api/v1`. The OpenAPI schema generated by FastAPI is the exact contract; this file is the map.

## Conventions

- Role checks are enforced per route on the server, plus ownership checks on every resource.
- Lists use cursor pagination.
- Errors share one shape: a machine-readable code and a translatable message key, never a sentence.
- Auth is by HttpOnly cookie. See [01-system.md](01-system.md).
- Uploads go straight from the browser to storage through a signed URL the API issues. The API then records the file after checking its type, size and checksum.

## Endpoints

| Area | Endpoints | Who |
| --- | --- | --- |
| Auth | `POST /auth/register`, `/auth/login`, `/auth/refresh`, `/auth/logout`, `/auth/verify-email`, `/auth/verify-phone`, `/auth/password-reset` | Public |
| Profile | `GET` and `PATCH /me`, `GET /me/donations` | Signed in |
| Causes, public | `GET /causes` (search and filters), `GET /causes/{slug}`, `GET /causes/{slug}/updates`, `GET /causes/{slug}/documents`, `GET /presenters/{id}/history`, `POST /causes/{slug}/reports` | Public |
| Causes, presenter | `POST /presenter/causes`, `PATCH /presenter/causes/{id}`, `POST .../documents`, `POST .../submit`, `POST .../updates` | Presenter |
| Assisted submission | `POST /admin/causes` (enter a cause on a presenter's behalf), `POST /admin/causes/{id}/handover` | Admin |
| Trust links | `GET /me/trust` (links out and in), `PUT /trust/{user_id}` (set level), `DELETE /trust/{user_id}`, `POST /trust/invitations` | Signed in |
| Paths and graph | `GET /causes/{slug}/trust` (viewer's paths to the presenter, overall counts), `GET /me/network` (viewer's graph, paged by distance) | Signed in; guests get counts only |
| Endorsements | `POST` and `DELETE /causes/{slug}/endorsements` | Signed in |
| Donations | `POST /donations` (returns checkout URL), `GET /donations/{id}`, `GET /donations/{id}/receipt` | Public or donor |
| Webhooks | `POST /webhooks/payments/{provider}` | Provider, signature-checked |
| Verification | `GET /verifier/queue`, `GET /verifier/causes/{id}`, `POST /verifier/causes/{id}/reviews` | Verifier |
| Disbursements | `POST /presenter/causes/{id}/disbursements`, `POST /admin/disbursements/{id}/approve`, `.../reject` | Presenter, admin |
| Admin | `GET /admin/users`, `/admin/causes`, `/admin/reports`, `/admin/audit-log`; `POST /admin/causes/{id}/suspend`, `/admin/donations/{id}/refund` | Admin |

## Rules specific to trust endpoints

- `GET /causes/{slug}/trust` returns only links the viewer may see: links whose author the viewer trusts, and links to the viewer.
- No endpoint returns the wider graph or lists another user's links.
- Path and network lookups are rate-limited.
